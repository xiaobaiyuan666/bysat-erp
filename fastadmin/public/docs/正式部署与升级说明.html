正式环境交付

正式部署与升级说明

适用于 ERP AI 管理系统正式版。

正式环境建议采用完整部署包首次安装，后续小版本升级使用 Patch 包或系统内在线更新。数据库更新必须走迁移链路，不建议直接手工覆盖线上库。

打开安装器 查看首次使用说明

推荐环境

Web / PHP PHP 8.1 或 8.2，站点根目录必须指向 fastadmin/public。
数据库 MySQL 5.7+ 或 8.0+，正式环境建议单独数据库。
必备扩展 pdo_mysql、curl、fileinfo、mbstring、json、bcmath
运维建议 正式上线前，建议在宝塔保留整站快照和数据库备份。

安装策略

  1. 新环境首次上线：使用完整正式包，安装模式选择 clean。
  2. 演示、培训或内部体验：可选择 demo 模式。
  3. 日常小版本升级：优先使用 Patch 包或在线更新。
  4. 跨版本或重大升级：建议先做库快照，再使用完整包。

在线更新策略

系统内已支持检查更新、代码备份、数据库 SQL 备份、数据库迁移账本和一键回滚。正式环境建议先在测试环境演练一次升级与回滚，再执行线上更新。
完整包 适合首次部署、跨版本升级、故障恢复和整站重装。
Patch 包 适合前端样式、小型功能、文案或流程类小版本更新。
数据库迁移 版本包含迁移时，系统会先做 SQL 备份，再按迁移账本顺序执行。
回滚原则 回滚会恢复代码备份和对应数据库备份，但仍建议保留宝塔层快照。

数据库迁移要求

  • 已发布的迁移文件不要直接改内容。
  • 需要新增结构时，创建新的 migration id。
  • 尽量让迁移可重复执行，或兼容旧数据。
  • 正式环境更新前，优先在测试库验证迁移结果。

官方说明

部署到不同公司时，可直接在“系统资料 -> 系统配置”中修改。
