正式版使用指引

首次使用说明

适用系统：ERP AI 管理系统。

这套系统定位为中小型互联网企业内部 ERP 管理系统，主线能力包括财务、客户与合同、项目协同、人员权限、审批日志和 AI 助手。建议首次上线使用 clean 模式，以正式流程配置真实账号和基础数据。

打开后台 查看部署与升级说明

首次登录后先做什么

  1. 使用默认管理员 admin / Admin@123 登录后台。
  2. 第一时间修改管理员密码、邮箱和昵称，避免多人共用超级账号。
  3. 进入“人员权限”，为财务、项目、运营、技术、客服分别建立真实账号。
  4. 进入“AI 助手 -> AI 设置”，填写正式环境的接口地址、模型名和 API Key。
  5. 进入“系统资料 -> 模块中心”，确认是否启用“项目运营插件”。

推荐初始化顺序

1. 系统配置 确认公司名称、版权信息、系统首页和基础显示信息。
2. 角色权限 按真实岗位分配权限，不建议多个同事共用管理员账号。
3. AI 配置 配置正式模型后，先做一次简单问答和一次首页分析测试。
4. 业务基础核对 检查财务中心、项目交付、项目运营的字段和流程是否符合公司现状。

AI 首次配置建议

请准备好 Base URL、API Key 和 Model。配置完成后，先在 AI 对话页测试一条简单问题，再在首页 AI 入口做一次业务分析，确认接口可用、响应时间正常。

正式环境上线前检查

  • 确认安装模式为 clean。
  • 确认站点根目录指向 fastadmin/public。
  • 确认数据库已做快照或备份。
  • 确认附件目录可写，服务器可正常出网。
  • 确认 AI Key、接口地址和模型名已经替换为正式环境配置。
  • 确认“系统资料 -> 在线更新”页面可以正常打开。

常见问题

安装器提示数据库无权限 不要求 root。请先在宝塔创建数据库，再把该数据库授权给当前账号。
安装后打不开后台 优先检查站点根目录是否指向 fastadmin/public，以及 PHP 版本和扩展是否符合要求。
AI 无法连接 优先检查接口地址、SSL 证书链、模型名和服务器出网能力。
升级后想回滚 进入“系统资料 -> 在线更新”，在升级记录中选择最近一次成功记录进行回滚。

版权与说明

登录页系统名称、后台左上角 Logo、官网入口和版权说明都在“系统资料 -> 系统配置”中维护。

如果不需要显示官网或版权说明，对应配置项留空即可。
