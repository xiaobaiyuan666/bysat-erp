# 最小自动化说明

这套最小自动化用于在正式包层面做一次完整冒烟，覆盖：

- 安装
- 登录
- 首页
- AI 页面
- 项目运营
- 财务
- 在线更新检查

## 脚本位置

- [run-minimal-automation.ps1](/C:/Users/Administrator/Documents/New%20project/scripts/run-minimal-automation.ps1)

## 默认运行方式

在仓库根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run-minimal-automation.ps1
```

默认行为：

- 自动选择 `output` 目录下最新的完整正式包
- 解压到临时目录
- 启动一套临时 PHP 站点
- 优先读取当前仓库 `fastadmin/.env` 的数据库连接配置
- 自动创建一个唯一的临时数据库
- 按 `clean` 模式安装
- 用 `admin / Admin@123` 完成登录和后台检查
- 更新检查默认会启用 `skip_ssl_verify`，避免本地 CA 证书链问题干扰结果
- 输出 `report.json` 和每一步对应的 HTML/JSON 原始响应

## 常用参数

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run-minimal-automation.ps1 `
  -PackageZip .\output\bysat-erp-fastadmin-baota-20260326-171131.zip `
  -MysqlUser root `
  -MysqlPassword root `
  -InstallMode demo `
  -Port 8096
```

可调参数包括：

- `-PackageZip`
- `-PhpPath`
- `-MysqlHost`
- `-MysqlPort`
- `-MysqlUser`
- `-MysqlPassword`
- `-MysqlPrefix`
- `-InstallMode clean|demo`
- `-AdminUsername`
- `-AdminPassword`
- `-Port`
- `-SkipUpdateSslVerify`
- `-OutputRoot`

## 输出位置

每次执行都会生成一个独立目录：

```text
output/automation/minimal-automation-时间戳/
```

目录中会包含：

- `report.json`
- `php-server.stdout.log`
- `php-server.stderr.log`
- `http/install.get.html`
- `http/install.post.json`
- `http/login.get.html`
- `http/login.post.json`
- `http/dashboard.html`
- `http/ai.html`
- `http/project-ops.html`
- `http/finance.html`
- `http/upgrade.html`
- `http/upgrade.saveconfig.json`
- `http/upgrade.checkupdate.json`

## 判定规则

脚本会在以下任一情况直接失败并返回非零退出码：

- 安装页打不开
- 安装返回失败
- 登录失败
- 首页 / AI / 项目运营 / 财务 / 在线更新页缺少关键标记
- 更新检查接口返回失败

## 适用场景

- 正式包出包后做一次最小验收
- 上线前本地或测试机自检
- 后续接 CI/CD 前的低成本基线检查
