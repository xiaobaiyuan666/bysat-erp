# 上线检查清单

## 一、环境检查

- 站点根目录已指向 `fastadmin/public`
- PHP 版本为 `8.1` 或 `8.2`
- MySQL 版本为 `5.7+` 或 `8.0+`
- 必要扩展已开启：`pdo_mysql`、`curl`、`fileinfo`、`mbstring`、`json`、`bcmath`
- 附件目录和运行目录具备写入权限

## 二、安装检查

- 首次上线使用 `clean` 模式
- 安装器页面可正常打开
- 安装完成页已显示后台地址
- 默认管理员可以正常登录
- 登录后已立即修改管理员密码

## 三、业务检查

- 公司名称、版权、官网信息已确认无误
- 财务中心基础字段与流程符合当前公司使用方式
- 客户与合同模块能正常打开与保存
- 项目交付模块能正常查看和录入
- 项目运营插件已按需启用
- 员工账号、权限组、审批链已完成初始化

## 四、AI 检查

- 已填写正式环境的 `Base URL`
- 已填写正式环境的 `API Key`
- 已填写正确的 `Model`
- AI 对话页能正常返回内容
- 首页 AI 快捷分析能正常完成一次分析

## 五、升级检查

- 在线更新中心可正常打开
- 当前环境已具备代码备份目录
- 数据库备份策略已确认
- 已准备完整包和 Patch 包
- 已预留回滚操作人和回滚窗口

## 六、上线后首日检查

- 管理员与关键岗位账号能正常登录
- 财务、项目、运营、技术等角色权限无越权问题
- 附件上传、附件查看、AI 调用都正常
- 服务器日志无明显报错
- 如启用在线更新，先完成一次测试环境演练
