# 首次使用说明

适用版本：ERP AI 管理系统正式版

## 1. 首次登录

- 后台地址：安装完成页会直接显示后台地址。
- 默认管理员：`admin / Admin@123`
- 第一次登录后，先修改管理员密码和邮箱。

## 2. 推荐初始化顺序

1. 进入 `系统资料 -> 系统配置`，确认公司名称、版权说明、固定首页是否正确。
2. 进入 `人员权限`，先建立公司内部真实账号，再按岗位分配权限组。
3. 进入 `AI 助手 -> AI 设置`，填写你的 OpenAI 兼容接口地址、模型名和 API Key。
4. 进入 `系统资料 -> 模块中心`，确认是否启用 `项目运营插件`。
5. 进入 `财务中心`、`项目交付`、`项目运营` 分别检查基础数据结构是否符合公司当前流程。

## 3. AI 首次配置

请准备以下信息：

- `Base URL`
- `API Key`
- `Model`

配置完成后，建议先做两次验证：

1. 在 `AI 助手` 页面发一条简单问题，确认能正常回复。
2. 在首页 AI 入口做一次简短分析，确认接口响应时间和结果格式正常。

## 4. 权限建议

正式环境建议至少拆成以下角色：

- 超级管理员：仅限少数负责人
- 财务
- 项目经理
- 运营
- 技术
- 客服

原则：

- 不要多人共用 `admin`
- 日常操作账号和超级管理员账号分开
- 先给最小权限，再逐步放开

## 5. 正式环境上线前检查

- 确认安装模式为 `clean`
- 确认站点根目录为 `fastadmin/public`
- 确认数据库已备份
- 确认附件目录可写
- 确认 AI Key 已替换为正式环境配置
- 确认在线更新中心可以正常打开

## 6. 在线更新建议

进入 `系统资料 -> 在线更新`：

- 正式环境建议优先使用 `Release` 包
- 小版本日常升级可以使用 `Patch` 包
- 升级前系统会自动做代码备份
- 若本次版本包含数据库迁移，系统会自动导出 SQL 备份

## 7. 回滚建议

如果更新异常：

1. 先进入 `系统资料 -> 在线更新`
2. 在更新记录里选择最近一次成功更新
3. 点击 `回滚到这里`
4. 回滚完成后重新检查后台是否正常

## 8. 常见问题

### 安装器提示数据库无权限

不是必须 root。
请在宝塔里先建库，再把该库授权给当前数据库账号。

### 安装后打不开后台

优先检查：

- 站点根目录是否指向 `fastadmin/public`
- PHP 版本和扩展是否符合要求
- 是否被缓存了旧入口

### AI 不通

优先检查：

- 接口地址是否正确
- 服务器是否能出网
- SSL 证书链是否完整
- 模型名是否真实可用

## 9. 系统展示信息

- 登录页系统名称、后台左上角 Logo、官网入口和版权说明都在 `系统资料 -> 系统配置` 中维护。
- 如果不需要显示官网或版权说明，对应配置项留空即可。
