# 正式版发布说明

版本代号：`v2026.03.26`
适用系统：ERP AI 管理系统

## 一、系统定位

本系统定位为中小型互联网企业内部 ERP 业务管理系统，围绕以下核心能力建设：

- 财务记账与付款附件管理
- 客户与合同管理
- 项目交付与协同
- 项目运营插件
- 员工权限与审批日志
- AI 助手与智能分析

其中，`项目运营` 已按插件化方式收口，APP 仅作为项目类型之一，不再把行业场景强耦合进主系统。

## 二、本次正式版重点

- 安装器已适配正式环境，支持 `clean` 和 `demo` 两种安装模式。
- 安装成功页会直接给出后台地址、默认账号和首次使用说明入口。
- 在线更新中心已支持代码备份、数据库 SQL 备份、迁移账本和回滚入口。
- 已支持完整部署包和 Patch 补丁包两种交付模式。
- 系统名称、版权和官网入口已改为后台系统配置维护，不再写死固定公司信息。
- 首页、AI 对话页、项目运营工作台已按正式使用场景做过一轮收整。

## 三、推荐使用方式

- 首次上线：使用完整正式包，安装模式选 `clean`
- 内部演示：使用完整正式包，安装模式选 `demo`
- 日常小版本升级：优先使用 Patch 包或后台在线更新
- 跨版本升级：先做整站和数据库快照，再执行升级

## 四、默认信息

- 后台入口：安装完成页会直接展示
- 默认管理员：`admin / Admin@123`
- 官网入口：在 `系统资料 -> 系统配置` 中按需填写；留空则不显示。

## 五、正式环境建议

- 不要多人共用管理员账号
- 正式 AI Key 与测试环境配置必须分开
- 升级前保留宝塔层的整站快照
- 先在测试环境演练升级和回滚，再执行线上更新

## 六、展示信息

登录页、后台 Logo、官网入口和版权说明均读取系统配置，部署到不同公司时可直接在后台修改。
