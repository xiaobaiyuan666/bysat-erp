# 正式部署与升级说明

## 一、正式部署建议

- 新环境首次上线：使用完整正式包
- 日常小版本升级：使用 Patch 包
- 重大升级或跨版本升级：先备份数据库，再使用完整包或 Release 包

## 二、宝塔推荐环境

- PHP：`8.1` 或 `8.2`
- MySQL：`5.7+` 或 `8.0+`
- 必要扩展：
  - `pdo_mysql`
  - `curl`
  - `fileinfo`
  - `mbstring`
  - `json`
  - `bcmath`

## 三、站点目录

站点根目录必须指向：

```text
fastadmin/public
```

## 四、数据库策略

- 正式环境推荐单独数据库
- 不建议和其他站点混用前缀
- 升级前建议保留宝塔数据库快照

## 五、升级策略

### 完整包

适合：

- 新装
- 重装
- 大版本切换
- 故障兜底恢复

### Patch 包

适合：

- 小版本更新
- 前端样式调整
- 小型功能补丁
- 后台文案和流程微调

## 六、在线更新能力

系统内已支持：

- 检查远端版本
- 自动代码备份
- 自动数据库 SQL 备份
- 数据库迁移账本
- 一键回滚

## 七、数据库迁移原则

- 已发布的迁移文件不要直接改内容
- 需要变更时，新增新的 migration id
- 尽量保持可重复执行或兼容旧数据

## 八、回滚说明

回滚会做两件事：

1. 恢复对应版本的代码备份
2. 如有对应数据库备份，则恢复对应 SQL

因此正式环境仍建议保留宝塔层面的整站快照。
