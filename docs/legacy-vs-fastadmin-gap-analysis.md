# 老系统与 FastAdmin 现状对比

## 已经补回来的能力

### 入口与工作台
- `经营驾驶舱` 已恢复，首页可以直达财务、项目、APP 运营、客户合同、审批和 AI。
- `财务工作台` 已恢复，包含待回款、待付款、待补附件和智能记账入口。
- `项目工作台` 已恢复，包含逾期任务、阻塞任务、待验收任务和负责人负荷。
- `APP 运营工作台` 已恢复，包含问题记录、研发联动、版本发布、资料中心等入口。

### 业务主线
- `财务中心`：财务流水、应收应付、附件补传、智能记账可用。
- `客户与合同`：客户档案、客户跟进、合同台账、审批中心、回款计划、付款计划可用。
- `供应商与费用`：供应商档案、费用申请、费用审批、费用转付款计划已补上。
- `项目交付`：项目台账、任务清单、项目工作台可用。
- `APP 运营`：APP 台账、问题记录、问题跟进、研发联动、版本发布、内部资料、里程碑、周报、风险问题可用。
- `人员与权限`：员工档案、后台账号、权限组、规则节点、操作日志可用。
- `AI 助手`：AI 工作台、模型配置、连接测试、模型探测、智能记账大模型解析可用。

### 权限与留痕
- FastAdmin 权限组已经按 ERP 业务模块重组。
- 财务、项目、客服、技术、运营、只读等角色的菜单和访问权限已同步。
- 业务留痕已经覆盖到财务、项目、APP 运营，以及本轮新增的供应商、费用申请、审批、付款计划。

## 和老系统相比仍然偏弱的地方

### 流程感还不够强
- FastAdmin 版已经有工作台，但很多流程仍然是“列表页 + CRUD”风格，操作引导不如旧版 Vue 工作台清晰。
- `APP 运营` 还可以继续收成更强的闭环页：问题 -> 跟进 -> 研发 -> 发版 -> 客户回告。
- `客户与合同` 虽然已经形成客户 -> 合同 -> 审批 -> 回款/付款主线，但审批规则、抄送和意见模板还比较轻。

### 企业管理深度还不够
- 现在有 `合同审批 / 付款审批 / 费用审批`，但还没有 `多级审批 / 抄送 / 条件审批 / 审批模板`。
- 还没有 `部门树 / 组织架构 / 数据权限范围` 这类正式企业系统常见能力。
- 还缺 `采购申请 / 采购单 / 供应商结算` 这类与付款计划进一步联动的后续模块。

### AI 还可以更深
- AI 工作台已经能用，但更多还是“分析和解析”。
- 还可以继续补：
  - 页面内一键追问 AI
  - AI 结果生成待办
  - AI 结果写回问题跟进、项目备注、财务备注
  - 票据图片识别后直接挂入智能记账

## 接下来最值得补的企业能力

按优先级建议是：

1. `多级审批 + 审批模板`
- 先把合同、费用、付款三条线统一到同一套审批规则里。

2. `组织架构 + 数据权限`
- 部门树、负责人范围、按部门看数据、按项目看数据。

3. `AI 写回业务`
- 不只分析，还要把 AI 结果转成待办、跟进记录或财务草稿。

4. `采购主线`
- 供应商 -> 费用申请 -> 采购单 -> 付款计划 -> 结算。

5. `轻量入口`
- 给客服、运营、财务做更轻的录入页，而不只是桌面后台列表。

## 当前结论

现在这套 FastAdmin 已经不再是“只剩 CRUD 表格的迁移版”，而是已经追回了：
- 驾驶舱
- 工作台
- 权限组
- 业务主线
- AI 和智能记账
- 客户合同主线
- 供应商与费用主线

但如果要更像正式企业系统，下一步不该再零碎补字段，而是继续补：
- `多级审批`
- `组织/数据权限`
- `AI 写回业务`
- `采购与结算链路`
